## 独立维护声明

**`mooncake.pgsty.com`** 以及 [`github.com/pgsty`](https://github.com/pgsty) 组织下的代码仓库（`pgsty/pg_mooncake`、`pgsty/duckdb_mooncake`、`pgsty/moonlink`）由 [**PGSTY (Pigsty)**](https://pigsty.io) 面向 PostgreSQL 开源社区独立维护。

本站点以及由 Pigsty / PGEXT 分发的软件包与 Mooncake Labs, Inc. 不存在隶属、官方背书或商业赞助关系。

## 第三方商标归属

- **Mooncake**、**pg_mooncake**、**duckdb_mooncake** 与 **Moonlink** 是源自 Mooncake Labs, Inc. 的项目名称，在本站中仅用于指代和描述对应的 PostgreSQL / DuckDB 开源扩展及其技术血统。
- **PostgreSQL** 与 **Postgres** 是加拿大 PostgreSQL 社区协会（PostgreSQL Community Association of Canada）的注册商标。
- **DuckDB** 是 DuckDB Foundation / DuckDB Labs 的商标。
- **Apache Iceberg**、**Apache Parquet**、**Apache Arrow** 与 **Apache** 是 Apache 软件基金会（Apache Software Foundation）的商标。
- **Delta Lake** 是 LF Projects, LLC 的商标。
- **Pigsty** 与 **PGSTY** 是冯若航（`@Vonng`）的商标。
